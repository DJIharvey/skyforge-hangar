# Skyforge Hangar

RC plane dogfight hangar.

Open phone.html or desktop.html. On tab 5 Account, type a plane secret code and tap Unlock plane.

The first plane (Skylark) and the first tank (Tank) are free. Tank Mk II and Tank Mk III stay locked until you enter their codes or buy them.

Master code: SKYFORGE

See CODES.md for every unlock code.
